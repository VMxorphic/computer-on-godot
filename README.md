# computer-on-godot
replicating a computer system in Godot 4.7.
# Description
A computer system made by me in Godot inspired by windows. This project has multiple apps, the ability to use multiple windows and resize them,and a taskbar with the apps previously used and other informational icons. This project is meant to work for game like Last Seen Online. For anyone to download in order to make it easier for others to use it in their own projects.  
# Apps
## On Computer
- <b>Browsing app</b>: 6 pages to search (---, ---, ---, ---, ---, ---)  
- <b>Gaming app</b>: 3 games (---, ---, ---)  
- <b>Trash/recycle app</b>: find files deleted / restore files
- <b>Files app</b>: find files 
- <b>Chatting app</b>: a chatting space where player can respond to messages sent my already made characters
- <b>Calculator app</b>: a app to do basic math problems
- <b>Paint app</b>: a app where player can paint
- <b>Sticky notes app</b>: a app that saves and displays what the player writes. Good for remembering stuff.

## On Taskbar
- <b>Weather</b>: When pressing the icon you can see the the temperature of the day
- <b>Search apps</b>: This opens a place that you can search all current apps on the computer.
- <b>Time zone and day</b>: See the day and time of the day.
- <b>Control audio or mute</b>: Control the SFX and Music volume or mute them.
- <b>Language (not implemented)</b>: Change the language of the OS.
